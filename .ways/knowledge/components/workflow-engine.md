# Workflow engine

Quick mode creates one checked implementation commit. Plan mode versions a proposal before execute, promote, or abandon. SDD certifies intake through close in order and supports autonomous/supervised and inline/delegated profiles. Delegated implementation accepts only commits integrated from declared isolated task worktrees.
